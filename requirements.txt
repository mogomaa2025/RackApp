# Application Overview

"Rackulator" is an application designed to calculate paint usage for various rack configurations. It has two primary sections:

1.  **Rack Page:** A user-facing section for viewing rack data.
2.  **Admin Panel:** A password-protected section for managing rack data.

# Core Features

*   **Rack Data Display:** Display rack data including fixed values and calculated values based on user selections of Main Category and Subcategory.
*   **Admin Panel:**
    *   Password-protected access (password: 25212521).
    *   Ability to edit Main Category names.
    *   Ability to edit Subcategory names.
    *   Ability to edit fixed data values (Description, Length_mm, Width_mm, Quantity_for_1_Rack).
    *   Ability to edit the calculation equations.
    *   Ability to add new categories (with subcategories and data).
    *   Ability to delete existing categories and subcategories.
    *   All changes are saved to a JSON file within the app's assets.
*   **Category Management:** Manage rack categories, subcategories, and their associated data.
